# エイジスイカ

スイカゲーム風の落ち物パズル。果物の代わりに人間が落ちてくる。

- 同じ年齢どうしがくっつくと年をとる：あかちゃん → 3歳 → 6歳 → 10歳 → 15歳 → 20歳 → 30歳 → 45歳 → 60歳 → 80歳
- 80歳どうしがくっついて100歳になると「銀のあかちゃん」に生まれ変わる
- 銀の80歳どうし → 「金のあかちゃん」、金の80歳どうし → ゴールの「金の100歳」
- 点線より上に2秒はみ出したらゲームオーバー
- 縦・横どちらの画面にも対応

物理演算は Matter.js（MIT License）。ゲーム本体は `app/src/main/assets/index.html`。
